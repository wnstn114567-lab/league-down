## easy 버전에서 바뀐 파일

- `js/data.js` – 173명 → 20명 (라인별로 고르게 나누려고 포지션은 한 라인만)
- `js/tier-data.js` – 라인마다 S·A·B·C에 한 명씩
- `js/guide.js` – 스킬 순서 목록에서 20명에 없는 챔피언 제외
- `team.html` – 예시 조합 3개를 20명 안에서 다시 구성
- `index.html` – 슬라이드 문구 "173명" → "20명"

나머지(HTML 구조, CSS, 기능)는 기존 버전과 같습니다.
