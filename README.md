| 폴더 | 설명 |
|---|---|
| [`original/`](original/) | 기존 버전 – 챔피언 전체, 티어표, 조합 만들기, 공략 (페이지 5개) |
| [`easy/`](easy/) | 쉬운 버전 – 푸드페스티벌 구조 그대로, 근본 챔피언 20명 (페이지 2개) |

## easy 버전 구성

- `index.html` – 메인 (메뉴 드롭다운 / 슬라이드 / 탭 / 배너 / 바로가기 / 팝업)
- `champion.html` – 라인별 4명씩 챔피언 20명, 라인 버튼으로 골라보기, 카드 누르면 팝업
- `css/style.css` – 스타일 하나
- `js/script.js` – 스크립트 하나 (메뉴, 슬라이드, 탭, 팝업, 라인 버튼)
- `img/` – 챔피언 아이콘, 일러스트, 슬라이드 이미지
